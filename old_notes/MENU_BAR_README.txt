Digi Suite menu bar companion: shares the main app model, displays current session, backup status and destination connectivity, runs incremental backups, pauses/resumes/stops active backups, toggles scheduled backups and optional macOS notifications, opens the main app, and quits. Closing the window should leave the menu bar app running. DS icon remains for Dock/Finder; the Dashboard uses the existing Digi Suite wordmark. Build on macOS with bash build.command. This package has not been compiled on macOS.\n
