# Digi Suite 20.11: install to Applications and Dock

```bash
cd "$HOME/Downloads/DigiSuite_20_11" && bash build.command
```

- When Digi Suite opens from anywhere other than Applications, it asks:
  Install in Applications? with a "Keep in Dock" checkbox (on) and
  "Don't ask again". Install copies it, adds the Dock icon if it is not
  already there, reopens from Applications and quits the old copy.
- An older Digi Suite in Applications goes to the Trash, not deleted.
- Digi Suite menu > Install in Applications / Dock… does the same any time,
  or adds the Dock icon if it is installed but missing from the Dock.
