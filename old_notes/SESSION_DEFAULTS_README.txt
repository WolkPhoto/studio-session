Digi Suite: Session-aware Processed Files defaults

When a session folder is selected or a saved workspace is opened, Processed Files automatically uses its Capture and Output subfolders when they exist.

Change buttons allow manual folder overrides. Reset restores the standard session folder. Overrides are saved in the .digitools workspace and are not overwritten by automatic defaults.

If a standard folder is missing, no alternative is guessed. The UI asks you to choose it.

This is the first incremental session-aware update, focused on Processed Files. Other tab-specific automatic configuration remains future work.

Build locally on macOS with your existing Desktop builder. Not compiled or tested on macOS in this environment.
